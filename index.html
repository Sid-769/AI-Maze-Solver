A* quick explanation:
g = cost so far from the start node (how far you’ve traveled).
h = estimated cost to reach the goal (heuristic).
f = g + h, the total priority (smaller f → explored first).

Think of f as a “score” for each cell (lower is better) A* expands nodes with the smallest f first, balancing distance traveled and estimated distance remaining.
On the grid, g = steps from start, h = Manhattan distance to goal.

BFS — Quick Overview
Breadth-First Search expands the maze level-by-level, ensuring the shortest path on any unweighted grid.
g: Distance from the start (number of steps taken).
f: Priority value (for BFS, f = g since all edges have equal cost).
Nodes Visited: Total number of cells explored during the search.
Path Turns: Number of direction changes along the final path.
Optimality Ratio: Path length divided by the Manhattan distance between start and goal.

DFS — Quick Overview
Depth-First Search explores the maze by going as far as possible along one branch before backtracking.
DFS does not guarantee the shortest path and is sensitive to recursion/stack depth.

Nodes Visited: Total explored cells.
Max Stack Depth: Deepest the DFS recursion/stack reached.
Dead Ends: Times the algorithm hit a cell with no unexplored neighbors.
Backtracks: Number of times DFS reversed direction due to dead ends.
Path Turns: Total direction changes in the final path.

DFS is useful for full exploration and maze generation, but not efficient for path optimality.

MDP metrics explained:
Slips / Deviations = times the agent moved in an unintended direction.
Failed Moves = times the agent attempted to move into a wall.
Total Reward = sum of step rewards collected.
State Values = expected cumulative reward from each cell.
Path Optimality Ratio = path length divided by shortest possible path.
Reward System- Step cost = -0.05, Goal reward = 10.
Stochasticity = actions succeed 80% of the time; 10% slip left/right.
