A* quick explanation:
g = cost so far from the start node (how far you’ve traveled).
h = estimated cost to reach the goal (heuristic).
f = g + h, the total priority (smaller f → explored first).

Think of f as a “score” for each cell (lower is better)
A* expands nodes with the smallest f first, balancing distance traveled and estimated distance remaining.

Example: On a grid, g = steps from start, h = Manhattan distance to goal.

MDP metrics explained:
Slips / Deviations = times the agent moved in an unintended direction.
Failed Moves = times the agent attempted to move into a wall.
Total Reward = sum of step rewards collected.
State Values = expected cumulative reward from each cell.
Path Optimality Ratio = path length divided by shortest possible path.
Reward System- Step cost = -0.05, Goal reward = 10.
Stochasticity = actions succeed 80% of the time; 10% slip left/right.
