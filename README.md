# CS3346_GroupProject

## Setup Instructions
1. **Install dependencies**
	Have Python 3.8+ and `pip` installed. Then run:
	```bash
	pip install -r requirements.txt
	```

2. **Run the application**
	Start the FastAPI server with:
	```bash
	uvicorn app:app --reload
	```

3. **Open the app**
	Visit [http://localhost:8000](http://localhost:8000) in your browser to use the Maze Solver UI.
